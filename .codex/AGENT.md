  brand: Aura

# Prompt

Create a premium luxury landing page...
```

## Prompt Grammar (APLCE Integration)

antlr

```
grammar AuraPrompt;

document
    : metadata body EOF;

metadata
    : FRONTMATTER yaml FRONTMATTER;

body
    : heading paragraph* block*;

heading
    : HASH TEXT;

paragraph
    : TEXT+;

block
    : code
    | quote
    | list;

list
    : DASH TEXT+;

code
    : TRIPLE_BACKTICK TEXT* TRIPLE_BACKTICK;
```

This parser becomes part of APLCE Compiler Engineering.

Bash

```
npm install -g @aura/prompt-cli
```

Bash

```
kubu prompt new

kubu prompt execute ui.watch.hero

kubu prompt search shader

kubu prompt compare ui.watch.hero

kubu prompt translate ui.watch.hero --lang ja

kubu prompt publish
